대표 결과 웹·복수 PDF 요약과 문서 비교를 Chrome Side Panel에 구현 · 우수논문상 동상

OVERVIEW

프로젝트 개요

Journal Mate는 읽고 있는 웹페이지나 논문 PDF의 본문을 추출해 요약·번역하고, 여러 문서의 공통점과 차이점까지 확인하는 연구 보조 확장 프로그램입니다. Chrome Side Panel 안에서 입력·요약 길이 선택·결과 확인을 이어가도록 구성했습니다.

PROBLEM & SOLUTION

문제 인식과 해결

긴 논문을 읽고 여러 편을 비교할 때는 핵심 내용을 따로 정리한 뒤 다시 대조해야 합니다. 단순히 요약만 생성하는 데서 멈추지 않고, 요약·번역·검증 역할을 분리해 결과를 점검하고 여러 문서의 비교까지 한 흐름에서 처리하는 것을 목표로 했습니다.

  • URL 모드에서는 활성 탭의 본문을 추출하고, PDF 모드에서는 PDF.js로 문서별 텍스트를 읽어 요약 입력으로 전달합니다.
  • Summarizer가 핵심 내용을 구조화하고 Translator가 한국어 표현을 정리한 뒤, Verifier가 사실·논리·문체를 확인하는 3개 역할의 처리 흐름을 설계했습니다. 요약 초안에 검토 의견을 반영할 지점을 분명히 하고, 필요하면 다시 생성해 최종 결과를 확정하도록 했습니다.
  • 짧게·보통·길게 요약 분량을 선택하게 하고, 응답은 스트리밍으로 받아 생성 중에도 Side Panel에서 확인할 수 있도록 구성했습니다.
  • 여러 PDF는 문서별 요약을 먼저 만든 다음 요약 결과를 비교해 공통점과 차이점을 정리하도록 했습니다.

IMPLEMENTATION

구현 내용

아래는 팀이 구현한 확장 프로그램의 주요 기능입니다. 저는 웹·PDF 본문 추출과 요약·번역·검증 흐름의 설계·구현을 담당했습니다.

현재 웹페이지 요약·번역

활성 탭의 본문을 가져와 Side Panel에서 요약 분량을 정하고 결과를 확인합니다.

PDF 입력과 문서별 처리

PDF 모드에서 파일을 추가하고 요약 또는 비교 작업을 선택합니다. PDF.js가 파일의 페이지별 텍스트를 추출합니다.

여러 PDF 요약과 비교

문서별 요약을 각각 표시하고, 요약 결과를 바탕으로 여러 논문의 공통점과 차이점을 정리합니다.

ARCHITECTURE

아키텍처

  • Manifest V3 Side Panel이 입력과 결과 화면을 담당하고, Chrome Scripting API로 활성 탭의 본문을 가져옵니다.
  • PDF.js로 PDF 페이지의 텍스트를 추출한 뒤 Background Service Worker가 OpenAI API 요청을 보내고 스트리밍 응답을 Side Panel에 전달합니다.
  • 복수 PDF는 파일별 요약을 만든 뒤 비교 요청으로 묶어 공통점·차이점 결과를 별도로 표시합니다.

TECH STACK

기술 구성

Chrome Extension · Manifest V3
Side Panel과 Background Service Worker를 사용해 브라우저 안에서 입력·요청·결과 흐름을 구성했습니다.
JavaScript · Chrome Scripting API
활성 탭에서 정보성 본문을 추출해 요약 입력으로 전달했습니다.
PDF.js
업로드한 PDF를 페이지 단위로 읽어 텍스트를 추출했습니다.
OpenAI API · Streaming
Background Service Worker에서 요약·비교 요청을 보내고 생성 중인 응답을 화면에 전달했습니다.

RESULTS

성과

  • URL 요약·번역, 복수 PDF의 개별 요약, 문서 비교를 하나의 Side Panel 안에 연결했습니다.
  • 짧게·보통·길게 요약 분량을 선택하고, 생성 중인 결과를 스트리밍으로 확인하는 화면을 구현했습니다.
  • 요약·번역·검증 역할과 PDF별 결과·문서 비교 흐름을 분리해 연구 자료를 단계적으로 살펴볼 수 있게 했습니다.
