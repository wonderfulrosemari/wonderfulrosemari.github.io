OVERVIEW

프로젝트 개요

Catch Me는 실종·목격 신고, 동물 보호소 정보, 입양 게시글과 실시간 채팅을 한곳에서 제공하는 하이브리드 앱 서비스입니다. 지도와 이미지 분석을 결합해 보호자와 입양자가 필요한 정보를 빠르게 찾도록 설계했습니다.

86.33% → 95%CLIP 검증 정확도 · 300장 · +8.67%p 향상
약 3만 장추가 파인튜닝 이미지

PROBLEM & SOLUTION

문제 인식과 해결

실종·보호·입양 정보가 여러 플랫폼에 흩어져 있고, 실종 후 7일 이내의 골든타임에 정보를 찾고 공유하기 어렵다는 문제를 해결하려 했습니다. 현장에서 바로 쓸 수 있도록 하이브리드 앱 형태로 접근성을 높였습니다.

  • 실종 신고 시간에 따라 지도 마커를 변화시키고, 마커 수에 따라 클러스터링해 제보 밀도를 보여줬습니다.
  • 위치와 가까운 순으로 유사 목격 제보를 추천해, 실종 신고 전 등록된 제보도 확인할 수 있게 했습니다.
  • 품종·색상 분류 성능을 높이기 위해 Google Open Images의 Dog 클래스를 바탕으로 약 3만 장의 이미지를 구성하고 CLIP 추가 학습을 직접 진행했습니다. 같은 300장 검증 세트에서 정답 수가 259장에서 285장으로 늘어 정확도가 86.33%에서 95%로 개선된 것을 확인했습니다.
  • 학습 결과를 서비스에 연결하는 작업까지 맡았습니다. 모델의 유사 이미지 결과에 위치 정보를 함께 반영해 목격 제보를 탐색하도록 구성했습니다.

IMPLEMENTATION

구현 내용

아래는 팀이 구현한 서비스의 주요 화면과 기능입니다. 저는 DB·공공 API 연동, CLIP 추가 학습과 정확도 검증, 모델 결과의 서비스 연동을 직접 담당했습니다.

지도에서 실종·목격 제보 확인

실종·목격 제보와 보호소 위치를 지도에 함께 표시해 주변 정보를 빠르게 살펴볼 수 있도록 했습니다.

골든타임과 제보 밀집도 표현

모든 신고를 같은 우선순위로 보여주면 긴급한 제보가 묻힐 수 있어, 실종 경과 시간에 따라 마커를 바꾸고 제보 밀집도를 클러스터 색상과 건수로 표현했습니다.

CLIP 모델 추가 학습과 검증

품종·색상 조합의 이미지를 추가 학습하고 같은 300장 검증 세트에서 전후 정확도를 비교했습니다. 이미지 한 장만으로 동일 개체를 단정하지 않도록, 유사도와 위치 기반 제보를 함께 확인하는 보조 판단 흐름에 연결했습니다.

목격 제보 작성

발견 장소와 시각, 동물의 외형 및 당시 상황을 입력해 구조에 필요한 맥락을 공유합니다.

입양 게시글 탐색

지역·나이·품종·색상 조건으로 입양 게시글을 좁혀 필요한 동물을 찾을 수 있습니다.

보호소 정보 필터링

품종, 성별, 털색 조건을 조합해 보호소 동물 정보를 탐색합니다.

ARCHITECTURE

아키텍처

  • 하이브리드 앱이 지도·신고·입양 화면을 제공하고, Spring Boot API가 서비스 도메인과 데이터를 처리합니다.
  • 유사 동물 탐색은 FastAPI의 CLIP 모델로 분리하고, MariaDB에 신고·보호소·입양 데이터를 관리합니다.
  • 보호소 공공 API 데이터는 정기 동기화해 서비스 내 정보와 연결합니다.

TECH STACK

기술 구성

Morpheus
WebView 기반 화면을 하이브리드 앱으로 제공했습니다.
Spring Boot · MariaDB
신고·보호소·입양·채팅 API와 관계형 데이터를 관리했습니다.
FastAPI · CLIP
동물 이미지 추론을 서비스 API와 분리해 처리했습니다.

RESULTS

성과

  • 약 3만 장의 이미지를 추가 학습해 CLIP 검증 정확도를 86.33%(259/300)에서 95%(285/300)로 개선했습니다.
  • 실종·목격·보호소·입양으로 흩어진 동물 정보를 한 서비스 흐름으로 통합했습니다.
  • 지도 시각화, 유사 이미지 탐색, 위치 기반 추천을 결합해 골든타임의 정보 탐색 경로를 만들었습니다.
