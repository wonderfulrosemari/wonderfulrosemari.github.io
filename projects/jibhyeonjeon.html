OVERVIEW

프로젝트 개요

홀가(家)분은 팀 집현전이 만든 시니어 다운사이징 지원 서비스입니다. 집을 매도한 뒤 확보할 수 있는 자금, 새 거주지의 안전·생활편의·자산안정, 노후 생활비를 함께 고려해 매물과 안정형 금융상품을 추천합니다.

PROBLEM & SOLUTION

문제 인식과 해결

추천에 사용하는 외부 데이터와 서비스에서 생성되는 분석 데이터를 지속적으로 갱신해야 했습니다. 제가 맡은 데이터 파이프라인에서는 외부 API 응답을 기다리는 일을 서비스 조회에서 분리하고, 정기 적재를 다시 실행해도 분석 데이터가 중복되지 않게 하는 데 집중했습니다.

  • 외부 API의 지연과 데이터 변동이 추천 화면에 영향을 주지 않도록 데이터를 미리 수집·정제하는 파이프라인을 서비스 조회와 분리했습니다.
  • 별도의 분석 적재에서는 개인정보를 제외한 MySQL 데이터 7종을 대상으로 삼았습니다. 워터마크로 변경분을 구분하고 스테이징 테이블과 MERGE를 사용해, 같은 작업을 재실행할 때 중복이 생기지 않도록 구성했습니다.
  • 초기 적재 19,624행을 원천 건수와 대조하고, 데이터 변경 없이 다시 실행했을 때 중복 적재 없이 건너뛰는 동작을 확인했습니다. 관련 단위 테스트 98개도 통과했습니다.
  • 서비스 이용이 적은 시간대를 고려해 매일 새벽 2시에 실행하도록 설정했습니다. 정기 적재 작업과 사용자의 조회 요청이 겹쳐 부하가 집중되는 상황을 줄이려는 운영상 판단이었습니다.

IMPLEMENTATION

구현 내용

아래는 팀이 구현한 서비스 주요 기능입니다. 저는 데이터 파이프라인·금융상품 추천·회원 관리·모니터링을 담당했습니다.

  • 매도 세금·중개보수를 반영한 순가용자금 계산
  • 맞춤형 온보딩과 페르소나 기반 매물 추천
  • 생활 인프라 점수와 이사 후 자금을 고려한 매물·금융상품 추천
  • 개인정보를 제외한 MySQL 분석 데이터 7종의 BigQuery 증분 적재
  • 관심 매물 비교와 종합 리포트 PDF 다운로드
  • OpenAI 요약과 CLOVA TTS 음성 안내
  • Prometheus·Grafana를 활용한 서비스 모니터링

DESIGN & PRODUCT

화면과 설계 자료

ARCHITECTURE

아키텍처

  • Vue.js·Pinia 프론트엔드가 설문과 추천 결과를 제공하고, Spring·MyBatis API가 회원·설문·추천 도메인을 처리합니다.
  • 외부 API의 응답 지연과 데이터 변동이 추천 화면에 영향을 주지 않도록 Python과 GCP(Cloud Scheduler·Cloud Run·BigQuery) 파이프라인에서 데이터를 미리 수집·정제해 서비스 조회와 분리했습니다. 별도로 개인정보를 제외한 7개 분석 데이터셋은 MySQL에서 BigQuery로 증분 적재했습니다. 적재 작업이 서비스 조회 부하와 겹치지 않도록 이용이 적은 시간대인 매일 새벽 2시에 실행되게 구성했습니다.
  • Prometheus가 서비스 상태를 수집하고 Grafana가 지표를 시각화하며, MySQL이 핵심 서비스 데이터를 저장합니다.

DB 설계

  • 각 도메인의 마스터 테이블에 대응하는 히스토리 테이블을 두어 변경 이력을 남기고, DBA가 데이터 변화와 이상 징후를 분석할 수 있게 했습니다.
  • 외부 추천 데이터 수집·정제와 별도로, MySQL 분석 데이터 7종을 BigQuery에 증분 적재하는 파이프라인을 구성했습니다. 워터마크, 스테이징 테이블, 멱등 MERGE, 건수 검증을 적용해 실패 시 중복이나 누락을 확인할 수 있게 했습니다.

TECH STACK

기술 구성

Vue.js · Pinia
설문 입력부터 결과 리포트까지의 화면 상태를 관리했습니다.
Java 17 · Spring MVC · MyBatis · MySQL
회원·설문·매물·금융상품 REST API를 구현하고 MyBatis Mapper의 SQL로 데이터를 조회·저장했습니다.
JWT · Spring Security(BCrypt)
JWT로 회원 인증을 처리하고 BCrypt로 비밀번호를 해시했습니다.
Apache Tomcat 9 · Gradle
WAR 형식으로 빌드하고 Tomcat 9에서 Spring 웹 애플리케이션을 구동했습니다.
GCP · Cloud Scheduler · Cloud Run · BigQuery
추천용 외부 데이터를 주기적으로 수집·정제하고, 분석 데이터를 BigQuery에 적재했습니다.
Prometheus · Grafana
서비스 지표를 수집하고 대시보드에서 확인했습니다.

RESULTS

성과

  • 매도 순가용자금, 주거 환경, 생활비, 금융상품을 한 흐름에서 검토하는 다운사이징 의사결정 경험을 구성했습니다.
  • 사용자 데이터 파이프라인, 유사 자산 금융상품 추천, 회원 관리, 서비스 모니터링을 구현했습니다.
  • 개인정보를 제외한 분석 데이터 7종(총 19,624행)을 MySQL에서 BigQuery로 매일 적재하도록 자동화했습니다. 초기 적재 건수를 대조하고, 변경 없는 재실행에서 중복 없이 건너뛰는 동작을 확인했으며 관련 단위 테스트 98개를 통과했습니다.

프로젝트 보완점과 개선 방향

  • 추천 결과에 시나리오 비교와 위험 고지, 사용자 피드백을 반영한 개인화 개선을 추가할 수 있습니다.
